POLICY One
y write-up:

---

**PolicyOne — AI-Powered Policy Compliance Platform**

A full-stack SaaS application that automates compliance auditing for corporate information security regulations (ISO 27001 / JIS Q 15001). The system ingests DOCX policy documents, splits them into structured sections, and runs LLM-based analysis to detect gaps, conflicts, and coverage issues across regulation sets — then generates a merged, corrected output document.

**Key Features:**
- **Standard Check** — maps each ISO/JIS requirement clause against a company's internal policies using hybrid semantic search; classifies coverage as sufficient / partial / insufficient
- **Regulation Cross-Check** — detects discrepancies between two internal regulations section-by-section (covered / conflict / sub-only / needs-review) with confidence scoring
- **Regulation Merge** — LLM-driven merge of a sub-regulation into a main regulation, producing a final DOCX and an annotated suggestion document
- **Real-time Streaming** — SSE-based live progress during analysis; results stream in as LLM judgments complete
- **Export** — CSV and DOCX export of all results

**Tech Stack:**

| Layer | Technologies |
|---|---|
| Frontend | Next.js 14 (App Router), TypeScript, Tailwind CSS, SWR, Recharts |
| Backend | Python, FastAPI, SQLAlchemy (async), Alembic |
| AI/ML | OpenAI (embeddings + LLM), Anthropic Claude, TF-IDF, hybrid vector retrieval |
| Database | PostgreSQL |
| Document Processing | python-docx, Markdown-based section splitting |
| Auth | JWT (HS256) |
| Infra | Background task queue, SSE streaming, async concurrency with semaphore control |
